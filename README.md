# 🔐 Password Generator (Python)

## 📌 Description
This is a simple command-line based Password Generator developed using Python.  
It generates strong and random passwords to enhance security.

## 🚀 Features
- Generates random passwords  
- Includes uppercase and lowercase letters  
- Includes numbers and special characters  
- User can define password length  

## 🛠️ Technologies Used
- Python  
- random module  
- string module  

## ▶️ How to Run
1. Clone the repository  
2. Open the project in VS Code or any IDE  
3. Run the Python file:

```bash
python password_generator.py
